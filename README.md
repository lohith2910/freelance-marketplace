# 🚀 Freelance Marketplace

> A full-stack freelance marketplace built with **Django**, enabling clients to post projects, freelancers to bid on jobs, and manage secure milestone-based payments.

---

## 📌 Overview

Freelance Marketplace is a web application that connects clients with freelancers. Clients can post projects, receive bids, hire freelancers, and manage payments, while freelancers can browse projects, submit proposals, and track their work.

---

## ✨ Features

- 🔐 User Authentication (Login & Registration)
- 👨‍💼 Client Dashboard
- 👨‍💻 Freelancer Dashboard
- 📢 Project Posting
- 💰 Project Bidding
- 📊 Budget Matching
- 💳 Razorpay Payment Integration

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/freelance-marketplace.git
```

Move into the project directory

```bash
cd freelance-marketplace
```

Create a virtual environment

```bash
python -m venv venv
```

Activate it

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the server

```bash
python manage.py runserver
```
